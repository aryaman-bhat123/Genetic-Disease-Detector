# 🧬 Genetic Variant Risk Detector

An AI-powered Python machine-learning prototype for analyzing genetic variant characteristics.

## ⚠️ Disclaimer

This project is an educational/research prototype.

It does NOT diagnose genetic diseases and should NOT be used for medical decisions.

The included training dataset is synthetic and was created solely to demonstrate machine-learning functionality.

## Features

- Genetic variant input
- Gene selection
- Molecular consequence classification
- Variant type
- Population allele frequency
- Conservation score
- Functional-impact score
- Family-history input
- Random Forest classification
- Probability estimation
- Model explanations
- Streamlit interface

## Machine Learning

The project uses:

- Random Forest
- One-hot encoding
- StandardScaler
- ColumnTransformer
- Scikit-learn Pipeline
- Stratified train/test split
- Accuracy
- ROC-AUC
- Confusion matrix
- Classification report
